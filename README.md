Карточка товара Teaboom.
Верстка интерактивной карточки товара «Ананасовый улун» для тестового задания.
- Стек:
  HTML5, CSS3 (Flexbox/Grid), JavaScript (Vanilla)
- Функционал:
  Переключение фасовки с динамическим обновлением цены и артикула.
  Адаптивность под Desktop (1440px), Tablet (768px) и Mobile (375px).
  Интерактивные состояния кнопки «В корзину».
- Запуск:
  Скачайте проект или клонируйте репозиторий.
  Откройте файл index.html в любом браузере.
